# 我的世界小游戏起源 EP04：空岛生存的起源

《我的世界小游戏起源》第四期：空岛生存（Skyblock）是从哪来的。
和第三期饥饿游戏一样**边玩一局边讲历史**（第一人称实况）；画面是 Three.js 现搭的方块世界，旁白、配乐、音效都由代码生成；
动作按原版的规则逐 tick 模拟（`src/motion.js`）。
